# MiniMakingProjekte – Selbstlernkurse

Kleine Making-Projekte als Selbstlernkurse für das Makermobil-Team. Jede Lektion ist in ca. 2 Stunden selbstständig machbar.

## Kurse

| Lektion | Projekt | Dauer | Ordner |
|---|---|---|---|
| 1 | Sticker für Kopfhörer designen (Blanko + Beispiele) | ca. 2 Std. | [`kurse/sticker-kopfhoerer/LEKTION-1.md`](kurse/sticker-kopfhoerer/LEKTION-1.md) |

## Ablage

- **GitHub (dieses Repo):** Kursmaterialien, Vorlagen, Checklisten
- **Google Drive (Ordner „MiniMakingProjekte – Selbstlernkurse"):** fertige Sticker-Dateien (SVG/PNG) hochladen, damit das Team sie nutzen kann

## Lektion ergänzen

Neue Lektion = neuer Ordner unter `kurse/` mit einer `LEKTION-X.md` nach dem Schema: Lernziele → Vorbereitung → Schritt-für-Schritt-Aufgaben → Checkliste → Abgabe.
