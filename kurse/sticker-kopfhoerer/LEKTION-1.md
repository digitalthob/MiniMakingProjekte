# Lektion 1: Sticker für Kopfhörer designen (Blanko + Beispiele)

**Dauer:** ca. 2 Stunden | **Level:** Einsteiger | **Tools:** Canva oder Cricut Design Space

## Lernziele

Nach dieser Lektion kannst du:

1. druck- und schneidbare Sticker in Canva bzw. Cricut Design Space erstellen
2. Blanko-Vorlagen (Kreis, Oval, Rechteck; 3–5 cm) als transparentes PNG oder SVG exportieren
3. Beispiel-Sticker im Makermobil-Design (Logo, „Property of", Nummern 1–10, Kopfhörer-Icon) umsetzen
4. Dateien korrekt speichern und im Team freigeben

## Schritt 1: Vorbereitung (15 Min)

- [ ] Tool auswählen:
  - **Canva** (canva.com) – einfache Designs + Druckvorlagen → empfohlen für den Start
  - **Cricut Design Space** (design.cricut.com) – präzise Schneidevorlagen
- [ ] Im **Makermobil-Account** einloggen. Kein Zugriff? → temporären Zugriff für Julie anfragen.
- [ ] Neues Design anlegen, Maßeinheit auf **cm** stellen.

## Schritt 2: Blanko-Vorlagen erstellen (30 Min)

- [ ] Form anlegen: **Kreis, Oval oder Rechteck**
- [ ] Größe: **3–5 cm** Durchmesser bzw. Seitenlänge
- [ ] Farben neutral halten: **weiß** oder **transparent**
- [ ] Export:
  - **PNG mit transparentem Hintergrund** (für Drucker)
  - **SVG** (für Cricut-Schneidepfade)
- [ ] **Canva-Tipp:** Hintergrund entfernen / transparent setzen → so bleiben die Sticker individuell beschriftbar.

## Schritt 3: Beispiel-Sticker erstellen (60 Min)

Erstelle je einen Sticker mit:

- [ ] **„Makermobil"** – Logo + Schriftzug
- [ ] **„Property of [Name]"** – für persönliche Kennzeichnung der Kopfhörer
- [ ] **Kopfhörer-Icon**
- [ ] **Nummern 1–10** (für Teams)

Vorgaben:

- **Farben:** Corporate Design Makermobil (Blau/Türkis)
- **Schrift:** gut lesbar ab 3 cm
- **Cricut-Hinweis:** Schneidepfade prüfen (Konturschneiden / „Cut Contour")

## Schritt 4: Speichern & Freigeben (15 Min)

- [ ] Dateibenennung: `sticker-[inhalt]-[form]-[groesse].svg/.png` (z. B. `sticker-makermobil-kreis-4cm.svg`)
- [ ] Dateien im **Google-Drive-Ordner „MiniMakingProjekte – Selbstlernkurse"** hochladen
- [ ] Freigabe für das **Team Makermobil** prüfen (Bearbeiten erlauben)
- [ ] Kurze Rückmeldung im Team-Kanal: Sticker fertig + Link

## Checkliste vor der Abgabe

| Kriterium | erfüllt? |
|---|---|
| Blanko-Vorlagen (2 Formen, transparent) | ☐ |
| Beispiel-Sticker (Makermobil, Property of, Icon, Nummern) | ☐ |
| PNG transparent **und/oder** SVG | ☐ |
| Größe 3–5 cm eingehalten | ☐ |
| Farben im Corporate Design | ☐ |
| In Drive hochgeladen & geteilt | ☐ |

## Reflexion

1. Welche Form hat sich am besten für die Kopfhörer geeignet?
2. Was würde ich beim nächsten Sticker anders machen?

## Weiterführend

- Canva-Hilfe: Hintergründe transparent setzen
- Cricut: Konturschneiden (Print then Cut) – Schneidepfade testen
- Nächste Lektion: Sticker auf Kopf-hörer-Arten anwenden / andere Geräte-Beschriftungen
